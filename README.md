# 워크보드 설치 가이드

비용 없이, 본인 구글 계정으로만 로그인해서 PC·태블릿·휴대폰에서 같은 데이터를 쓰는 개인용 업무·일정 관리 도구입니다.

- **화면(앱 파일)**: GitHub Pages에 올립니다. 무료이고, 주소는 `https://내아이디.github.io/workboard/` 형태가 됩니다.
- **로그인 · 데이터 저장**: Firebase(구글)의 무료 요금제(Spark)를 씁니다. 카드 등록이 필요 없습니다.
  - 무료 한도: 저장 1GiB, 하루 읽기 5만 건 · 쓰기 2만 건. 혼자 쓰기에는 충분합니다.
- **보안**: 앱 코드는 공개 저장소에 올라가지만, 데이터는 Firebase 보안 규칙으로 **지정한 구글 계정만** 읽고 쓸 수 있습니다.
  - config.js에 들어가는 Firebase 설정값은 비밀번호가 아니라 공개돼도 되는 값입니다.

소요 시간: 처음 한 번 약 15–20분

---

## 1단계 · GitHub에 올리기 (약 5분)

1. [github.com](https://github.com)에 가입하거나 로그인합니다.
2. 오른쪽 위 **+ → New repository**를 누릅니다.
   - Repository name: `workboard`
   - **Public** 선택 (무료 계정은 Public 저장소만 Pages를 쓸 수 있어요)
   - **Create repository**를 누릅니다.
3. 만들어진 저장소 화면에서 **uploading an existing file**을 누릅니다.
4. 압축을 푼 폴더 안의 파일 **전부**를 끌어다 놓고 **Commit changes**를 누릅니다.
   - 올릴 파일: `index.html`, `config.js`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png`, `firestore.rules`, `README.md`
5. 저장소의 **Settings → Pages**로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)** 선택 후 **Save**
6. 1–2분 뒤 같은 화면 위쪽에 주소가 나타납니다. 예: `https://내아이디.github.io/workboard/`
   - 지금 열면 "설치를 마무리해 주세요"가 보이는 게 정상입니다. 이 상태에서도 **이 기기에서 체험하기**로 먼저 써 볼 수 있어요.

## 2단계 · Firebase 만들기 (약 10분)

1. [console.firebase.google.com](https://console.firebase.google.com)에 본인 구글 계정으로 들어갑니다.
2. **프로젝트 추가** → 이름 `workboard` → Google 애널리틱스는 **사용 안 함** → 만들기
3. 로그인 켜기
   - 왼쪽 메뉴 **빌드 → Authentication → 시작하기**를 누릅니다.
   - **로그인 방법** 탭에서 **Google**을 **사용 설정**합니다. 지원 이메일은 본인 메일을 선택하고 저장합니다.
4. 로그인 허용 주소 추가
   - Authentication → **설정** 탭 → **승인된 도메인** → **도메인 추가**
   - `내아이디.github.io`를 입력합니다. `https://`나 `/workboard`는 빼고 입력하세요.
5. 데이터베이스 만들기
   - **빌드 → Firestore Database → 데이터베이스 만들기**를 누릅니다.
   - 위치는 **asia-northeast3 (서울)**을 고릅니다. 한 번 정하면 바꿀 수 없어요.
   - **프로덕션 모드로 시작**을 고르고 만듭니다.
6. 보안 규칙 넣기
   - Firestore → **규칙** 탭을 엽니다.
   - 내용을 전부 지우고 `firestore.rules` 파일 내용을 붙여넣은 뒤 **게시**합니다.
   - 규칙 안의 이메일(`nagyeong55555@gmail.com`)이 로그인할 계정과 같은지 확인하세요.
7. 웹 앱 등록하고 설정값 받기
   - 왼쪽 위 톱니바퀴 → **프로젝트 설정** → 아래 **내 앱**에서 **웹(</>)** 아이콘을 누릅니다.
   - 앱 닉네임 `workboard`를 입력하고 등록합니다. Firebase Hosting 체크는 하지 않습니다.
   - 화면에 나오는 `const firebaseConfig = { ... }` 안의 값 6줄(apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId)을 복사해 둡니다.

## 3단계 · 설정값 붙여넣기 (약 2분)

1. GitHub 저장소에서 `config.js`를 열고 연필(✏️ Edit) 버튼을 누릅니다.
2. `"여기에-..."`로 된 값들을 2-⑦에서 복사한 값으로 바꿉니다.
3. `allowedEmail`이 로그인할 구글 메일과 같은지 확인하고 **Commit changes**를 누릅니다.
4. 1–2분 뒤 주소를 새로고침하고 **Google 계정으로 로그인**을 누릅니다.
5. 처음 들어가면 "워크보드 시작하기" 4단계가 나옵니다: 근무 기준 → 이미 쓴 휴가·유연근무 → 분류·직원 → 추천 반복업무. 다 입력하면 바로 사용할 수 있어요.

## 4단계 · 휴대폰에 앱처럼 설치

- **아이폰 (Safari)**: 주소 열기 → 로그인 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드 (Chrome)**: 주소 열기 → 로그인 → 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- 홈 화면 앱에서는 로그인을 한 번 더 해야 할 수 있어요.
  - 로그인 창이 열리지 않으면 Safari·Chrome 탭에서 그대로 써도 됩니다. 기능은 같아요.

## 알림 받는 방법

웹 앱은 꺼져 있을 때 서버에서 알림을 보낼 수 없어서(무료 범위 기준), 두 가지 방법을 준비했습니다.

1. **캘린더 파일**: 설정 → **캘린더 파일 내보내기(.ics)** → 파일을 휴대폰 캘린더(아이폰 캘린더·구글 캘린더)에 추가하면 1주·1일·1시간 전에 알림이 옵니다.
   - 일정이 많이 바뀌었으면 다시 내보내세요.
   - 개별 일정은 항목 수정 화면의 **구글 캘린더에 추가**로도 넣을 수 있어요.
2. **이 기기 알림**: 설정 → **이 기기 알림 켜기**
   - 워크보드가 열려 있거나 백그라운드에 있을 때 시작 1시간 전, 마감 1일·1주 전에 알려줍니다.

## 데이터 옮기기 · 백업

- 설정 → **전체 백업(.json)** 으로 모든 데이터를 파일로 받을 수 있어요.
- 다른 곳에서 쓰던 데이터를 옮길 때는 설정 → **백업 불러오기**를 씁니다.
  - Claude에서 쓰던 워크보드도 같은 방법으로 옮길 수 있어요.
- 한 달에 한 번 정도 백업해 두기를 권합니다.

## 자주 묻는 문제

- **"이 주소가 Firebase 승인된 도메인에 없어요"**: 2-④에 `내아이디.github.io`가 들어갔는지 확인하세요.
- **"저장 권한이 없어요"**: 2-⑥ 규칙이 게시됐는지, 규칙의 이메일과 로그인한 메일이 같은지 확인하세요.
- **수정한 내용이 안 보임**: GitHub에 올린 뒤 1–2분 기다리고 새로고침하세요. 휴대폰 앱은 한 번 껐다 켜면 새 버전을 받습니다.
- **다른 사람이 주소를 알면?**: 화면은 보이지만 로그인이 막혀서 데이터는 볼 수 없어요.

## 프로그램 고치기 · 업데이트

- 코드는 이 GitHub 저장소에 있는 파일이 전부예요. Claude를 포함해 어떤 방법으로 고쳐도 됩니다.
- 새 파일을 받으면 저장소에서 **Add file → Upload files**로 같은 이름 파일을 올리고 **Commit changes**를 누르세요. 같은 이름이면 덮어써져요.
- 데이터는 Firebase에 있어서 파일을 바꿔도 지워지지 않아요.
- `config.js`는 다시 올리지 마세요. Firebase 설정값이 들어 있어요.

## 편의 기능 요약

- 입력: `+이름`으로 함께하는 사람, `#`·`@`·`+` 입력 시 자동완성, 빈 칸일 때 최근 입력 표시, 템플릿 불러오기
- 할 일 옆 **미루기** 버튼, 지연 여러 건 한 번에 옮기기
- 완료·삭제·미루기·끌어서 이동 직후 **되돌리기**
- PC 주간·월간에서 일정 끌어서 옮기기 / 휴대폰: 좌우로 밀어 날짜 이동, 할 일 오른쪽으로 밀어 완료
- 주간 보고 자동 작성, 대표님 급한 업무(밀리는 업무 자동 조정 + 안내문), 오늘 챙길 위임 메시지
- 입력: `10/17~18`·`토~일` 기간, `13~18시`·`10:30-12:00` 시간대 → 일정으로 저장
- 프로젝트·행사에서 생긴 할 일은 캘린더에 `약칭·할 일`로 표시 (설정에서 끄기 가능)
- 30일마다 백업 안내, 출근 시각 아침 요약 알림 (이 기기 알림을 켠 경우)

| 키 | 동작 |

| N | 입력 |
